Place the Space Mono woff2 files here with the exact filenames below so the site can load them locally:

- space-mono-300.woff2  (weight 300)
- space-mono-400.woff2  (weight 400, regular)
- space-mono-700.woff2  (weight 700)

How to get them:
1. Visit https://fonts.google.com/specimen/Space+Mono
2. Use the Download family button to get the font package.
3. Convert/ensure you have woff2 files (most packages include woff/ttf — use a converter if needed).
4. Rename the files to the names above and drop them in this folder.

After placing files, reload the site. The fonts are preloaded and declared via @font-face in style.css.
