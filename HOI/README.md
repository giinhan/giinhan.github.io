# HOI 아카이브

기존 About의 HOI! 버튼으로 열던 Content DNA Test 원본입니다.

- 실행: `Content_DNA_Test_revised.html`을 브라우저로 열면 됩니다.
- 다시 연결: 사이트 루트 기준 `HOI/Content_DNA_Test_revised.html`을 버튼의 `href`로 지정하세요.
- 화면 스타일과 실행 스크립트가 HTML에 포함되어 있어 별도 설치 없이 열 수 있습니다.
- 결과 이력은 브라우저의 localStorage에 저장됩니다. 기존 Google Sheets 전송 기능은 인터넷 연결 및 외부 서비스 설정에 따라 동작합니다.

현재 About의 Dearest 버튼은 `HOI/index.html`의 10페이지 그림 편지에 연결되어 있습니다.

## 그림 편지

- `index.html`: 10페이지 본문
- `presentation.css`: 종이 질감, Pretendard, 반응형 화면과 편지 모션
- `presentation.js`: 이전·다음, 페이지 선택, 좌우 방향키 이동
- `assets/`: 페이지별 그림과 로컬 Pretendard 폰트 (폰트 라이선스 포함)

현재 그림은 `assets/final/page-01.jpg`부터 `page-10.jpg`까지의 최종 수정본입니다. 둥근 팔다리와 손·발, 하얀 진돗개와 흰머리 할아버지, 살짝 컬이 있는 단발머리, 지인이 운전하는 베이지색 차를 반영했습니다. 초기 그림은 `assets/page-01.jpg`부터 `page-10.jpg`, 단순화한 이전 그림은 `assets/simple/`에 보관되어 있습니다. 그림 제작 프롬프트는 각 버전 폴더의 `ILLUSTRATION-PROMPTS.md`를 참고하세요.

그림 편지도 `index.html` 파일을 브라우저로 직접 열어 볼 수 있습니다.
